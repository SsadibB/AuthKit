# Google Login Demo (sample)

Import this sample from Package Manager → Auth Login (PlayFab) → Samples.

1. Create **Auth Login → Auth Settings** and paste your Google Web client ID.
2. Open a scene, add an empty GameObject, attach `GoogleLoginSampleUI`.
3. Assign the Auth Settings asset on `AuthManager` (created at runtime if missing).
4. Build to a signed Android device. Editor sign-in reports that an Android build is required.
